# 影片上字幕工作說明（KONOKI 專用・桌面版 Claude Code）

> 使用方式：把整個 `video-kit/` 資料夾複製到桌機，素材影片放進 `input/`，
> 在桌面版 Claude Code 開「本機」工作階段並指向這個資料夾。Claude 會自動讀這份說明。
> 一律以**繁體中文**回覆。擁有者顯示名稱為 **KONOKI**。

主角：IVE 安俞真（🐶）與金秋天（🐿️）。「文件夾」是兩人的 CP 稱呼（Fallderz），字幕或標題出現時照寫。

---

## 一、KONOKI 的固定需求（每支影片都照辦，不必再問）

1. **不更動影片規格**：解析度、長寬比、影格率不變；檔案大小盡量貼近原檔。
   燒字幕需要重新編碼時，用 libx264 two-pass、位元率設成原檔影像位元率；**音軌直接複製（`-c:a copy`）不重編**。
2. **字幕自行翻譯**：理解前後文與語順後翻成**繁體中文（台灣用語）**；專有名詞一律依「三、專有名詞表」。
3. **字幕樣式**：**黑底白字**；沒特別說明時一律**畫面下方置中**；一句一行，太長就依語氣停頓拆成兩句先後播放。
4. **字型統一用粉圓體（Huninn）**：放在 `fonts/Huninn-Regular.ttf`（沒有就先下載，見「五、環境準備」）。
5. **標題句**：KONOKI 若給一句標題，翻譯後**全程放在畫面左上方**，字級以**不遮到人物**為準（720px 寬約 22px，比例縮放）。
6. **全片都要有字幕**：KONOKI 給的原文／逐字稿只是參考；沒涵蓋但有人在說話的片段，也要自己聽取（看辨識結果）翻譯補上，前後文合理通順即可。
7. **參考譯文優先**：KONOKI 若另外給參考譯文（例如 Gemini 的翻譯），**以參考譯文的內容為準**，Claude 只負責依聲音停頓切句、配時間、統一專有名詞與稱謂。
8. **多支影片合併**：給多支片段時，依對白前後順序剪成一支；交界若有重複的話，在停頓處切掉重複的部分。影格率不同時取較高的（30 與 60 合併成 60，不丟原始畫格）。
9. **女性稱謂**：確認指代女性時，一律用「**妳**」「**她**」（不用「你」「他」），即使參考譯文寫「你」也要改。
10. **發話者 emoji**：參考字幕若在句首放動物 emoji 代表發話者（🐶＝俞真、🐿️＝秋天，其他成員依 KONOKI 給的 emoji），字幕要**保留 emoji 在句首**；括號內的描述（例如「（台下鼓譟）」「（三人一起…）」）也照樣當一句字幕顯示。這類字幕要用彩色 emoji，請用 PNG 圖層做法（見「四、技術備註」）。
11. **參考字幕的順序要依聲音判斷**：KONOKI 給的參考字幕順序不一定和實際說話順序相同，要依辨識結果調整先後，必要時在交付時說明調整了哪幾句。
12. **其他位置的說明文字**：KONOKI 指定「畫面最上方置中」等位置時照辦（同樣黑底白字、粉圓體，全程顯示、不遮到人物）。
13. **成品**輸出到 `output/`，檔名為「原檔名_中字.mp4」；同時輸出字幕檔（`.ass`）方便日後修改。

## 二、標準流程

1. **確認素材**：`ffprobe` 看解析度、影格率、位元率、長度；有多支時先判斷前後順序。
2. **語音辨識**：`python tools/transcribe.py input/xxx.mp4`
   → 產生 `work/xxx.words.json`（逐字時間）與 `work/xxx.txt`（可讀版）。
   使用 faster-whisper `large-v3-turbo`、開 VAD 過濾（避免安靜段落幻聽），並把專有名詞表當提示詞。
3. **翻譯與切句**：對照 KONOKI 給的逐字稿／參考譯文與辨識結果，寫出 `work/xxx.subs.json`：
   ```json
   {"title": "左上標題（沒有就省略或留空）",
    "lines": [[開始秒, 結束秒, "字幕文字"], ...]}
   ```
   - 斷句點選在辨識結果裡的停頓（字與字間隔較大處）。
   - 每句至少顯示約 1.2 秒；相鄰句之間沒有停頓時讓字幕直接接續，不要閃空白。
   - 辨識結果不確定的地方，在交付時列出來給 KONOKI 確認，不要默默猜。
4. **燒字幕**：`python tools/burn.py input/xxx.mp4 work/xxx.subs.json`
   → 自動依影片尺寸產生 ASS 字幕（粉圓體、黑底白字、下方置中、左上標題），two-pass 編碼、音軌直接複製。
5. **抽查**：每支抽 4–8 個時間點截圖（`ffmpeg -ss 秒 -i output/... -frames:v 1 check.png`），確認字幕沒超出畫面、沒擋臉、時間對得上。不必逐分鐘看。
6. **交付**：回報成品路徑、規格（解析度／影格率／大小與原檔比較），附一張「時間 → 字幕」表；有疑問的句子另外列出。

長片（例如 30 分鐘直播）同樣流程；字幕表只需列出有疑問的段落，不必整份貼出。

## 四、技術備註

- 字幕用 ASS 格式燒進畫面（`BorderStyle=3` 不透明黑底框）。ASS 不支援彩色 emoji；
  若字幕一定要彩色 emoji（例如 🐶🤭），改用 Playwright 把該句渲染成透明 PNG 再用 ffmpeg `overlay` 疊上。
- 發言是英文（例如海外演唱會）時，辨識要用 `--lang en`；現場歡呼聲大時，辨識結果容易重複或亂掉，改成每 20–30 秒一段分開辨識比較穩。
- PNG 圖層疊加時，**只裁出字幕那一條區域再疊**（例如 720×180），不要疊整張畫面大小的透明圖，否則 2 分鐘直式影片也要十幾分鐘才輸出完。
- 字級參考：底部字幕約為畫面寬度的 4.2%（720px 寬 → 30px），標題約 3%（→ 22px），黑底框距底約 5%。
  `burn.py` 已自動依影片寬度換算；直式／橫式影片都適用。
- Windows 路徑有中文或空白時，指令裡的路徑要加雙引號。

## 五、環境準備（第一次使用時）

1. 安裝 Python 3.10 以上與 ffmpeg（Windows：`winget install Gyan.FFmpeg`；Mac：`brew install ffmpeg`）。
2. `pip install -r tools/requirements.txt`
3. 下載粉圓體：`python tools/get_font.py`（從 Google Fonts 下載到 `fonts/`）。
4. 第一次執行 `transcribe.py` 時會自動下載辨識模型（約 1.6GB）。
   有 NVIDIA 顯示卡會自動使用；只有處理器也能跑，但 30 分鐘音訊可能要辨識 20–60 分鐘。
