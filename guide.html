CHAPTER 1網站是怎麼運作的

  • 前台：網站首頁，所有人都能瀏覽。
  • 館員後台：admin.html，只有完成設定的編輯者能新增、修改、刪除紀錄。
  • 文字資料（日期、標題、內容、分類…）存在 GitHub 儲存庫 slam0615/moments。
  • 照片與影片以原檔上傳到 Google 雲端硬碟的共用資料夾「Fallderz 素材」。
  • 按下「儲存並發佈」後，約 1～2 分鐘前台就會更新。

因此每位編輯者都需要兩把「鑰匙」：

鑰匙用途怎麼取得
GitHub 權杖寫入文字資料擁有者邀請你成為協作者 → 你自己建立權杖（第 3 章）
Google 授權上傳照片與影片擁有者共用資料夾並把你加為測試使用者 → 你用自己的 Gmail 登入（第 3 章）
共同編輯者擁有和擁有者相同的後台權限：可以新增、編輯、刪除所有紀錄，也能匯出與匯入備份。

CHAPTER 2擁有者：新增共同編輯者 由 slam0615 操作

先向對方要兩樣資料：GitHub 使用者名稱（不是 email）和 Gmail 信箱。

  • GitHub 協作者：開啟 儲存庫 Settings → Collaborators → Add people → 輸入對方的 GitHub 使用者名稱 → 送出邀請。
  • 雲端資料夾：在 Google 雲端硬碟對上傳資料夾按右鍵 → 共用 → 輸入對方的 Gmail → 權限選 編輯者 → 傳送。
  • Google 測試使用者：開啟 Google Auth Platform → 目標對象 → 測試使用者 → Add users → 輸入對方的 Gmail → 儲存（最多 100 人）。
  • 把這份手冊的網址和 OAuth 用戶端 ID 傳給對方（如果用戶端 ID 已寫進網站設定，就不用另外提供）。

CHAPTER 3共同編輯者：第一次設定 約 10 分鐘

建議用電腦完成第一次設定；之後用手機也能上傳。

步驟 1　準備 GitHub 帳號

  1. 沒有帳號的話，到 github.com/signup 免費註冊。
  2. 把你的 GitHub 使用者名稱和 Gmail 告訴擁有者，等擁有者完成第 2 章。

步驟 2　接受 GitHub 邀請

  1. 打開 GitHub 寄來的邀請信，或直接前往 github.com/slam0615/moments/invitations。
  2. 按 Accept invitation。

步驟 3　建立你自己的 GitHub 權杖

  1. 開啟 建立 classic token（連結已預先勾選好權限）。
  2. Note：Fallderz Moments。
  3. Expiration：建議選 90 days，到期再建立新的。
  4. Select scopes：確認只勾選 public_repo。
  5. 拉到最下面按 Generate token，複製以 ghp_ 開頭的權杖。
權杖只會顯示一次，請先貼到後台（步驟 5）。權杖等同你的鑰匙，不要傳給任何人，也不要貼在聊天室。
為什麼不是 Fine-grained token？因為儲存庫屬於擁有者的個人帳號，協作者的 Fine-grained token 無法存取它，所以共同編輯者要用 classic token。

步驟 4　確認雲端資料夾已共用給你

打開 Google 雲端硬碟 →「與我共用」，應該能看到上傳資料夾，而且你的權限是「編輯者」。看不到的話請擁有者確認第 2 章。

步驟 5　填寫後台的連線設定

  1. 開啟 館員後台，會自動跳出「連線設定」（之後可按右上角「連線設定」再打開）。
  2. GitHub 帳號：一律填 slam0615（儲存庫擁有者，不是你自己的帳號）。
  3. 儲存庫名稱：moments；分支：main。
  4. 存取權杖：貼上步驟 3 的權杖。
  5. OAuth 用戶端 ID：填擁有者提供的那一組（已自動帶入就不用改）。
  6. 上傳資料夾：保持預設即可。
  7. 按「儲存並連線」，出現「GitHub 連線成功」就完成了。

步驟 6　連結 Google 雲端硬碟

  1. 按後台上方的「連結 Google 雲端硬碟」。
  2. 選擇擁有者共用資料夾給你的那個 Gmail 帳號。
  3. 看到「Google 尚未驗證這個應用程式」時，按「繼續」（這是擁有者自己建立的私人應用程式）。
  4. 勾選允許存取 Google 雲端硬碟 → 繼續。
  5. 上方出現兩個 ✓ 就代表一切就緒：
Google 授權約 1 小時後失效，下次上傳時會自動跳出授權視窗，再按一次允許即可。GitHub 權杖則會保存在這台裝置的瀏覽器裡，換裝置要重新填寫。

CHAPTER 4新增一則紀錄

按左上角「＋ 新增紀錄」，依序填寫：

欄位說明
日期（必填）可選 2021/12/01 到今天；過了午夜就能選隔天。日期是 9/1 或 9/24 時會顯示 🎂 提示。
標題這一天的小標題，最多 80 字。
資訊來源網址（選填）原始貼文、文章、直播頁面的網址，前台會顯示在內容最下方。
內容可換行；文字裡的網址會自動變成連結。
分類標籤點選預設分類（可複選）；其他標籤在下方輸入後按 Enter 或逗號。
照片／影片點擊或拖曳檔案到虛線框，可一次選多張照片、多支影片。檔案會在按「儲存並發佈」時才上傳。
加入連結貼上 YouTube、X、Instagram 或雲端硬碟連結，前台會直接嵌入顯示。

整理媒體

  • ★：設為便利貼的代表縮圖。
  • ↑ ↓：調整顯示順序。
  • ✕：移除（尚未儲存前移除不會上傳）。
  • 說明文字：顯示在照片下方，可留空。

儲存

  1. 按右下角「儲存並發佈」。
  2. 畫面下方會顯示上傳進度（例如「上傳中 1/3：IMG_0001.jpg　45%」），大型影片需要一些時間，上傳完成前請不要關閉頁面。
  3. 出現「已儲存！前台約 1 分鐘後更新」即完成。
上傳的檔案會自動命名為「日期_標題_序號」，並設為「知道連結的任何人可檢視」，前台才能顯示。新上傳的影片需要 Google 處理幾分鐘才能播放。

CHAPTER 5編輯與刪除

  • 編輯：在左側清單點選紀錄（可用搜尋框找），修改後按「儲存並發佈」。
  • 刪除：打開紀錄後按左下角「刪除這則」並確認。
  • 刪除紀錄或移除媒體時，雲端硬碟裡的原始檔案會保留，不會被刪除；需要的話請到雲端硬碟手動處理。
  • 多人同時編輯不同紀錄不會互相覆蓋；但請避免兩個人同時編輯同一則，以後存檔的版本為準。
  • 匯出備份：下載全部文字資料（JSON 檔）。匯入備份會取代目前所有資料，請謹慎使用。

CHAPTER 6分類、生日與日期規則

預設分類

YouTube Berriz Universe 花絮 綜藝 Bubble Instagram FanClub LIVE FanSign

請優先使用預設分類，前台才能正確篩選；自訂標籤請保持一致的寫法（例如都用「生日」，不要混用「生日快樂」）。

生日紀錄

日期為 9 月 1 日或 9 月 24 日的紀錄，前台會自動加上彩帶、蛋糕和戴派對帽的狗狗鼠鼠，不需要另外設定。

日期

時間軸從 2021 年 12 月 1 日開始，以台北時間為準，每天午夜自動延伸到新的一天。

CHAPTER 7前台瀏覽方式

  • 預設：打開網站時顯示「本月」的紀錄。
  • 選年份：只顯示該年的紀錄；再選月份：只顯示該年該月。再按一次已選的月份會回到整年。
  • 全部：顯示所有紀錄。
  • 分類：只顯示該分類，可和年份、月份一起使用。
  • 搜尋：搜尋全部時間的標題、內容與標籤。
  • 便利貼／列表：切換兩種瀏覽方式；新→舊／舊→新：切換排序。
  • 點開紀錄後可用 ← → 切換上下則；網址可以直接分享給別人。

CHAPTER 8安全守則

  • 每個人使用自己的權杖，不要共用、不要傳給別人。
  • 在公用或別人的電腦上使用後，請到「連線設定」按「清除權杖」。
  • 懷疑權杖外流時，立即到 GitHub → Settings → Tokens 刪除，再建立新的。
  • 網站與上傳的照片影片是公開的，請勿上傳私密或不適合公開的內容。
  • 上傳到資料夾的檔案擁有者是上傳的人，佔用的是上傳者自己的雲端硬碟空間。

CHAPTER 9常見問題與錯誤訊息

看到的訊息原因與解決方式
權杖無效或已過期權杖輸入錯誤或已到期，請重新建立權杖（第 3 章步驟 3）並貼上。
找不到儲存庫，或權杖沒有存取權①「GitHub 帳號」要填 slam0615 ② 尚未接受協作邀請 ③ 權杖沒有勾選 public_repo。
這個權杖沒有寫入權限尚未成為協作者，或權杖權限不足。請確認已接受邀請。
找不到分支「分支」請填 main。
access_denied／存取遭拒你的 Gmail 不在 Google 測試使用者名單，請擁有者加入（第 2 章）。
origin_mismatch擁有者的 OAuth 用戶端沒有加入網站網址，請通知擁有者。
找不到上傳資料夾登入的 Google 帳號沒有該資料夾的權限，或資料夾網址錯誤。請確認用的是被共用的 Gmail。
沒有權限把檔案放進資料夾你的資料夾權限是「檢視者」，請擁有者改成「編輯者」。
已取消 Google 授權授權視窗被關掉了，再按一次「儲存並發佈」或「連結 Google 雲端硬碟」。若視窗沒跳出，請允許瀏覽器的彈出式視窗。
前台沒有更新等 1～2 分鐘，再按 Ctrl+Shift+R（Mac：Cmd+Shift+R）重新整理；手機請關掉分頁重開。
照片顯示不出來剛上傳的檔案需要幾分鐘處理；若是手動貼的雲端連結，請把共用設定改成「知道連結的任何人」。
日期選不到明天只能選到今天（台北時間），午夜後就能選新的一天。

其他問題請截圖後聯絡網站擁有者。

CHAPTER 10擁有者：移除共同編輯者 由 slam0615 操作

  1. 儲存庫 Settings → Collaborators → 對方旁的 Remove。對方的權杖會立即無法寫入。
  2. 雲端資料夾 → 共用 → 把對方改成「移除存取權」。
  3. （可選）Google 測試使用者中刪除對方。

所有新增與修改都會留在 GitHub 的歷史紀錄中（儲存庫的 Commits 頁面），可查看是誰在什麼時候做了哪些變更。
