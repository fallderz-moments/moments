      CHAPTER 1通過後：第一次設定 約 10 分鐘

      建議用電腦完成第一次設定；之後用手機也能上傳。

      步驟 1　接受 GitHub 邀請

      1. 打開 GitHub 寄來的邀請信，或直接前往 網站儲存庫的邀請頁面。
      2. 按 Accept invitation。邀請 7 天內有效，過期請 KONOKI 重新邀請。

      步驟 2　建立你自己的 GitHub 權杖

      1. 開啟 建立 classic token（連結已預先勾選好權限）。
      2. Note：Fallderz Moments。
      3. Expiration：建議選 90 days，到期再建立新的。
      4. Select scopes：確認只勾選 public_repo。
      5. 拉到最下面按 Generate token，複製以 ghp_ 開頭的權杖。
      權杖只會顯示一次，請直接貼到後台（步驟 4）。權杖等同你的鑰匙，不要傳給任何人，包括 KONOKI。在公用電腦使用後，請到「連線設定」按「清除權杖」。

      步驟 3　確認雲端資料夾已共用給你

      打開 Google 雲端硬碟 →「與我共用」，應該能看到 KONOKI 共用的資料夾，而且你的權限是「編輯者」。

      步驟 4　填寫後台的連線設定

      1. 開啟館員後台（就是這個頁面），會自動跳出「連線設定」（之後可按右上角「連線設定」再打開）。
      2. 存取權杖：貼上步驟 2 的權杖。
      3. 進階設定（儲存庫位置）會依網站網址自動帶入，不用填寫。
      4. OAuth 用戶端 ID：填 KONOKI 提供的那一組（已自動帶入就不用改）。
      5. 上傳資料夾：貼上 KONOKI 私下提供的資料夾網址（只會存在你的瀏覽器中）。
      6. 按「儲存並連線」，出現「GitHub 連線成功」就完成了。

      步驟 5　連結 Google 雲端硬碟

      1. 按後台上方的「連結 Google 雲端硬碟」。
      2. 選擇你提供給 KONOKI 的那個 Gmail。
      3. 看到「Google 尚未驗證這個應用程式」時，按「繼續」（這是 KONOKI 為本網站建立的私人應用程式）。
      4. 在權限畫面勾選「查看、編輯、建立及刪除您所有的 Google 雲端硬碟檔案」→ 繼續。沒有勾選的話上傳會失敗。網站只會把檔案放進共用資料夾，不會讀取你其他的檔案。
      5. 上方出現兩個 ✓ 就代表一切就緒：
      設定完成後，請繼續看下一章「新增一則紀錄」，以及編輯守則與常見問題。
      Google 授權約 1 小時後失效，下次上傳時會自動跳出授權視窗，再按一次允許即可。GitHub 權杖會保存在這台裝置的瀏覽器裡，換裝置要重新填寫。

      CHAPTER 2新增一則紀錄

      按左上角「＋ 新增紀錄」，依序填寫：

      欄位說明
      日期（必填）可選 2021/12/01 到今天；過了午夜就能選隔天。日期是 9/1 或 9/24 時會顯示 🎂 提示。
      標題這一天的小標題，最多 80 字。
      資訊來源網址（選填）原始貼文、文章、直播頁面的網址，前台會顯示在內容最下方。
      系列（選填）同一件事分成多則時填同一個系列名稱，前台會自動串起整個系列（上一則／下一則與清單）。
      內容可換行；文字裡的網址會自動變成連結。
      分類標籤點選預設分類（可複選）；其他標籤在下方輸入後按 Enter 或逗號。
      照片／影片點擊或拖曳檔案到虛線框，可一次選多張照片、多支影片。檔案會在按「儲存並發佈」時以原檔上傳到雲端資料夾備份。原始貼文網址請填在「資訊來源網址」。

      整理媒體

      • ★：設為便利貼的代表縮圖。
      • 🎞：（雲端影片）重新擷取影片封面。上傳影片時會自動擷取一個畫面當封面，舊的影片可用這個按鈕補上。
      • ↑ ↓：調整顯示順序。
      • ✕：移除（尚未儲存前移除不會上傳）。
      • 說明文字：顯示在照片下方，可留空。

      儲存

      1. 按右下角「儲存並發佈」。
      2. 畫面下方會顯示上傳進度（例如「上傳中 1/3：IMG_0001.jpg　45%」），大型影片需要一些時間，上傳完成前請不要關閉頁面。
      3. 出現「已儲存！前台約 1 分鐘後更新」即完成。
      上傳的檔案會自動命名為「日期_標題_序號」，並設為「知道連結的任何人可檢視」，前台才能顯示。影片會自動擷取一個畫面另存為「…_cover.jpg」當封面；新上傳的影片需要 Google 處理幾分鐘才能播放。

      CHAPTER 3編輯與刪除

      • 編輯：在左側清單點選紀錄（可用搜尋框找），修改後按「儲存並發佈」。
      • 刪除：打開紀錄後按左下角「刪除這則」並確認。刪除別人建立的紀錄前，請先和 KONOKI 確認。
      • 刪除紀錄或移除媒體時，雲端硬碟裡的原始檔案會保留，不會被刪除。
      • 多人同時編輯不同紀錄不會互相覆蓋；但請避免兩個人同時編輯同一則，以後存檔的版本為準。
      • 匯出備份：下載全部文字資料（JSON 檔）。匯入備份會取代目前所有資料，請先和 KONOKI 確認再使用。

      生日紀錄

      日期

      時間軸從 2021 年 12 月 1 日開始，以台北時間為準，每天午夜自動延伸到新的一天。

      CHAPTER 5編輯守則與安全

      編輯守則

      • 日期以「我們得知的時間點」為準：同一件事分階段曝光時，請依曝光日期分成不同則紀錄。
        例：2026/9/22 透過文字得知兩人去約會、相關照片 9/24 才發出來 → 分成 9/22（文字）與 9/24（照片）兩則。
      • 同一系列用「系列」欄位串起來：同一件事分成好幾則時，每一則的「系列」都填完全相同的名稱（例如 東京燒鳥約會，可從建議清單選既有系列）。前台會在每則紀錄下方顯示「本系列」清單與上一則／下一則，讀者不用另外篩選；分類標籤照常選擇即可，兩者互不影響。
      • 雙人直播有大量糖點時：在「資訊來源網址」附上直播連結，節錄的片段集中在同一則紀錄，並在內文整理重點摘要（建議附上時間點），不要拆成很多則。
      • 盡量附上資訊來源網址，方便大家查證。
      • 網站與上傳的照片影片是公開的，請勿上傳私密、未公開或不適合公開的內容。
      • 大幅修改或刪除既有紀錄前，先和 KONOKI 討論。

      帳號安全

      • 只使用你自己的權杖，不要共用、不要傳給任何人。
      • 在公用或別人的電腦上使用後，請到「連線設定」按「清除權杖」。
      • 懷疑權杖外流時，立即到 GitHub → Settings → Tokens 刪除，再建立新的，並告知 KONOKI。
      • 每次存檔都會以你的 GitHub 使用者名稱公開留下紀錄（不會顯示 email）。
      • 你上傳到資料夾的檔案，擁有者是你自己，佔用的是你的雲端硬碟空間。

      CHAPTER 7前台瀏覽方式

      • 預設：打開網站時顯示「本月」的紀錄。
      • 選年份：只顯示該年的紀錄；再選月份：只顯示該年該月。再按一次已選的月份會回到整年。
      • 全部：顯示所有紀錄。
      • 分類：只顯示該分類，可和年份、月份一起使用。
      • 搜尋：搜尋全部時間的標題、內容與標籤。
      • 便利貼／列表：切換兩種瀏覽方式；新→舊／舊→新：切換排序。
      • 點開紀錄後可用 ← → 切換上下則；網址可以直接分享給別人。

      CHAPTER 8停止擔任共同編輯者

      1. 告訴 KONOKI，KONOKI 會移除你的 GitHub 協作權限與資料夾共用。
      2. 到 GitHub → Settings → Tokens 刪除為本網站建立的權杖。
      3. 在使用過的每台裝置開啟後台 →「連線設定」→「清除權杖」。
      4. （可選）到 Google 帳戶 → 第三方連結 移除本網站的存取權。

      你已經新增的紀錄會保留在網站上；你上傳的檔案仍在你自己的雲端硬碟中，如需刪除請先和 KONOKI 討論，以免前台的照片或影片無法顯示。
